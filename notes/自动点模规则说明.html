01 一、自动点模规则概述 ▲

自动点模是 MES 系统中定时执行的存储过程，用于自动统计模具的点模数据。

核心逻辑

  1. 每天 9:00 和 21:00 自动触发
  2. 查询 tb_mes_mold_use 表获取模具上机记录
  3. 排除试模记录（is_test = 1）
02 二、关键 SQL 脚本 ▲ 
/* 自动点模核心查询 */
SELECT
    mold_code,
    COUNT(*) AS use_count,
    SUM(CASE WHEN is_qualified = 1 THEN 1 ELSE 0 END) AS qualified_count
FROM tb_mes_mold_use
WHERE create_time >= @start_time
  AND create_time < @end_time
  AND is_test = 0
GROUP BY mold_code;
03 三、注意事项 ▲

点模脚本执行前需要检查 tb_mod_sta_sync 表的 is_sync 字段，确保数据同步已完成。

风险点

风险 说明 处理方式
重复执行 同一时间段多次点模 使用 is_sync=1→2 控制重入
数据延迟 MOM 写入未完成 跳过 is_sync=1 的记录
试模干扰 试模记录混入统计 必须过滤 is_test=1

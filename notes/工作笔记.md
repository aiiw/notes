# 公式速查手册（来自你的历史表）

真实公式 + 用法说明，可直接改单元格引用。

## 长公式

多层拼接的业务公式。

### 示例（同类约 953 次）

- 来源：`01-知识库\aiiw\工作日志\个人日常工作登记表 (1).xlsm` / `日常工作登记表!C44`
- 标签：DATE, INT, MONTH, WEEKDAY, YEAR, 多层嵌套, 长公式

```excel
=IF(H44="","","第"&INT((B44-DATE(YEAR(B44),MONTH(B44),1)+WEEKDAY(DATE(YEAR(B44),MONTH(B44),1),2)-1)/7)+1&"周")
```

## LET + XLOOKUP 动态查找去重

先 XLOOKUP 取值，再用 TEXTSPLIT/UNIQUE/TEXTJOIN 去重拼接，适合一格多值。

### 示例（同类约 300 次）

- 来源：`02-业务模块\模具周转\模块资料\立库\20260804095006.20260804152548347.xlsx` / `汇总!E2`
- 标签：OR, TRANSPOSE, XLFN.LET, XLFN.TEXTJOIN, XLFN.TEXTSPLIT, XLFN.UNIQUE, XLFN.XLOOKUP, 多层嵌套, 跨表, 长公式

```excel
=_xlfn.LET(_xlpm.res,_xlfn.XLOOKUP(D2,Sheet!D:D,Sheet!O:O,"无数据"),IF(OR(_xlpm.res="无数据",_xlpm.res=""),_xlpm.res,_xlfn.TEXTJOIN(",",TRUE,_xlfn.UNIQUE(TRANSPOSE(_xlfn.TEXTSPLIT(_xlpm.res,",",,TRUE))))))
```

## 多层嵌套

- 来源：`01-知识库\aiiw\工作日志\个人日常工作登记表 (1).xlsm` / `日常工作登记表!C3`


### 示例（同类约 4 次）

## OFFSET 动态标题/区域

## TEXTJOIN + UNIQUE 文本去重

把逗号分隔值拆开、去重、再拼回。

### 示例（同类约 8 次）

- 来源：`模具周转模块\立库\按托盘统计立库模拟条码数量.xlsx` / `Sheet2!D3`
- 标签：TRANSPOSE, XLFN.TEXTJOIN, XLFN.TEXTSPLIT, XLFN.UNIQUE, 多层嵌套, 长公式

```excel
=_xlfn.TEXTJOIN(",",1,TRANSPOSE(_xlfn.UNIQUE(TRANSPOSE(_xlfn.TEXTSPLIT(C3,",")))))
```

## SUMIFS 本月汇总

配合 TODAY/EOMONTH 做当月合计。

### 示例（同类约 2 次）

- 来源：`AI\个人日常工作登记表 (1).xlsx` / `临时工作计划!J1002`
- 标签：DATE, EOMONTH, MONTH, SUMIFS, YEAR, 多层嵌套, 长公式

```excel
=SUMIFS(J:J,B:B,">="&DATE(YEAR(TODAY()),MONTH(TODAY()),1),B:B,"<="&EOMONTH(TODAY(),0))
```

## 嵌套 IF 状态判断

超时/测试中/分档等业务状态。

### 示例（同类约 1 次）

- 来源：`原来的py\品检中心-管理报表清单2.17\品检中心管理报表清单 2.17\F.PZB.0045.00 测试报告（成分不及格测试报告模板）.xlsx` / `Sheet1!N3`
- 标签：FIND, HYPERLINK, ISNUMBER, MONTH, 多IF, 多层嵌套, 跨表, 长公式

```excel
=IF(K3="","无",IF(ISNUMBER(FIND("成",#REF!)),HYPERLINK(".\检测报告\"&MONTH(Q2)&"月\"&#REF!&".pdf","。"),HYPERLINK(".\检测报告\"&MONTH(Q2)&"月\"&#REF!&".xls","。")))
```

### 示例（同类约 1 次）

- 来源：`原来的py\品检中心-管理报表清单2.17\品检中心管理报表清单 2.17\F.PZB.0045.00 测试报告（成分不及格测试报告模板）.xlsx` / `Sheet1!R3`

```excel
=IF(P3="","未填日期",IF(AND(P3>Q3,Q3=""),"测试中…",IF(OR(Q3>P3,Q3=""),"超时","及时")))
```
